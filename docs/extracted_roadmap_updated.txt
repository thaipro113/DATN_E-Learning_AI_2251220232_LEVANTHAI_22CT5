AI Tutor Agent có thể sử dụng các tool nội bộ như get_user_progress(), get_skill_score(), get_current_lesson() và get_quiz_result() để trả lời dựa trên dữ liệu học tập thực tế.
7.2 AI sinh câu hỏi
Input: topic, level, số lượng, type và context. LLM trả JSON theo schema; backend validate; Teacher preview/edit/approve trước khi lưu/publish.
API: POST /api/v1/ai/quizzes/generate
7.3 Cá nhân hóa và Recommendation
Quiz score + wrong questions + completion + study time + topic + level → Learning Analytics → Skill Score → Weak Topic → Rule-based Recommendation.
Baseline có thể dùng: SkillScore = 0.6 × QuizScore + 0.2 × Completion + 0.2 × RecentPerformance. LLM chỉ hỗ trợ giải thích recommendation, không tự quyết định điểm.

Không triển khai AI tự chấm điểm trong MVP. Multiple Choice/True-False/Fill Blank dùng rule-based scoring; Writing/Speaking AI evaluation chỉ là hướng phát triển.

12. AI Architecture
LLM dùng cho AI Tutor Agent và AI Quiz Generator. Learning Analytics/thuật toán dùng cho Skill Score, weak-topic detection và recommendation ranking. LLM chỉ giải thích recommendation; không cần tự train LLM.
AI Tutor Agent có thể sử dụng các tool đọc course/lesson/progress/quiz result. RAG là phần mở rộng: tài liệu → extract → chunk → embedding → vector store → retrieve → LLM.

23. Kết luận
Phạm vi phù hợp nhất cho đồ án cá nhân là ReactJS + TypeScript, Django REST Framework, PostgreSQL và LLM API. Django tổ chức theo Modular Monolith với Accounts, Courses, Learning, Assessments, AI, Recommendations và Quiz Import.
Ba điểm AI cốt lõi của sản phẩm là AI English Tutor Agent, AI Generate Quiz và Personalized Learning/Recommendation. Upload Quiz là chức năng nghiệp vụ hỗ trợ giáo viên, không tính là AI. Đây là phạm vi đủ lớn để có chiều sâu nhưng vẫn kiểm soát được cho một người hoàn thành.

3. Giai đoạn 1 – Kick-off
Chốt đề tài: Xây dựng nền tảng E-learning tiếng Anh tích hợp trí tuệ nhân tạo hỗ trợ học tập và cá nhân hóa lộ trình.
Actors: Student, Teacher, Admin.
Core value: học tập, đánh giá, AI feedback, cá nhân hóa và giảm thời gian tạo Quiz.
Definition of Done: code chạy; API có validation/permission; test luồng chính; tài liệu và evidence được cập nhật.
Success metrics: core flow end-to-end; AI Tutor và AI Quiz có eval set ≥20 case; Quiz Import parse đúng file mẫu; Recommendation có lý do dựa trên learning data.

9. Giai đoạn 8 – 4 AI/Intelligent Features
AI English Tutor
React → POST /api/v1/ai/tutor/chat → Django AITutorService → LLM → validation → lưu conversation/message → React.
AI sinh câu hỏi
Input: topic, level, quantity, type, context → LLM JSON schema → backend validation → Teacher Preview/Edit/Approve → Database → Publish.
Cá nhân hóa
Learning data → Analytics → Skill Score → Weak Topic → Recommendation. Baseline: SkillScore = 0.6 × QuizScore + 0.2 × Completion + 0.2 × RecentPerformance.
Upload Quiz
XLSX/CSV → Parser → Mapping → Validation → Group Topic → Quiz/Question/Option → Preview → Teacher Approve → Publish. File chuẩn ưu tiên parser; AI chỉ hỗ trợ semantic mapping/format không chuẩn.
